# 업데이트 내역

## 2026-11-09

- 처음 만들었어요. PDF 파일을 올리면 실제 책처럼 페이지를 넘겨 읽을 수 있는 전자책 뷰어가 생겼어요.
- 책을 넘기는 느낌(3D 접힘, 두 페이지 펼침), 글자 확대·축소, 전체화면 보기를 지원해요.
- 올린 파일은 브라우저 안에서만 읽히고 어디에도 저장되지 않아요.
- 화면이 좁으면 한 장씩, 넓으면 두 장씩 펼쳐서 보여줘요. 키보드 화살표나 드래그로도 넘길 수 있어요.
- 표지에서부터 뒷표지까지 책 전체를 넘길 수 있고, 페이지 번호 입력으로 바로 이동할 수 있어요.
- PDF 안에 목차가 있으면 '목차' 버튼이 생겨서 눌러서 이동할 수 있어요.
- '홀수 페이지 오른쪽' 버튼을 누르면 홀수 페이지가 오른쪽에 오도록 전체 배치가 바뀌어요. 선택한 내용은 다음에도 기억돼요.
- '업데이트 내역' 버튼을 PDF 선택 버튼 옆에 크게 두었어요. 누르면 바뀐 내용이 날짜별로 한눈에 보여요.
- 페이지를 넘길 때 스크롤이 깜빡이며 책이 떨리던 현상을 고쳤어요. 이제 흔들림 없이 부드럽게 넘어가요.
